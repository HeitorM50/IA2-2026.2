# Metadados da futura release do dataset

Este diretório contém licença e citação das anotações produzidas para a issue #49.
Os slides e o texto integral extraído não fazem parte da release.

A versão corrente é `0.1.0-draft` e não deve ser citada como versão final.
A versão `1.0.0` será criada somente depois da revisão cruzada, do congelamento dos hashes e do depósito no Zenodo.

O dataset final deverá conter os dez campos definidos em `data/dataset-schema.json`.
Respostas e evidências do split de teste devem permanecer privadas durante os ajustes do sistema.
